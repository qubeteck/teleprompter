# User Guide

## Creating scripts
- Click "New script" from dashboard or library.
- Edit in Markdown mode with the formatting toolbar.
- Autosave runs as you type; changes persist locally.

## Importing
- Use "Import" in library or editor. Supports TXT, MD, HTML, DOCX, PDF, RTF, JSON exports, and images.
- For scanned PDFs/images, enable OCR (local). Review extracted text in the preview.

## Reading (Teleprompter)
- Open a script and click "Read" or "Quick read".
- Adjust speed (WPM) and direction in controls/settings.
- Use Space to play/pause, F for fullscreen, C to show/hide controls.
- Countdown arms at start; press Space during countdown to start now.
- Mirror for on-camera rigs. Use focal line/fade for readability.
- Save preferences as presets.

## Voice follow
- Open voice panel in reader. Grant mic permission if prompted.
- Speak along; the script advances based on matched phrases. Timed scrolling pauses while listening.

## Recording
- Open camera panel. Grant camera/mic permission.
- Choose quality and start/stop recording. Download the local file.

## Remote control
- Open remote panel in reader to generate a session/QR. Pairing uses same-browser BroadcastChannel; network cross-device requires additional transport/server.

## Backups
- Settings → Data → Backups: export full backup or restore from file.
- Restore offers merge (safe) or replace (with optional safety backup).

## Trash
- Deleted scripts go to Trash. Restore or permanently delete.
